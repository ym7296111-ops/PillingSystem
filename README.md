# نظام الإدارة العامة لحسابات المشتركين - إدارة الإيصالات والخصومات
## Subscriber Accounts Management System

نظام ويب احترافي لإدارة حسابات المشتركين وفق الهيكلية التنظيمية الرباعية، مع إدارة الإيصالات والخصومات المستوردة وحساب الأرصدة وفق السنة المالية (1 يوليو - 30 يونيو).

**يعمل بالكامل بدون Backend باستخدام IndexedDB (Dexie.js)**

## 🏗️ الهيكلية التنظيمية

```
قطاع (Sector)
  ← فرع (Branch) - كود رقمين 00-99
    ← مجموعة (Group) - كود 1-8 (حد أقصى 8 لكل فرع)
      ← منطقة (Area) - كود 7 أرقام (أول رقم = كود المجموعة)
        ← مشترك (Subscriber) - رقم حساب 9 أرقام
```

**مثال كود المنطقة:** المجموعة 3، المنطقة 1234 → `3001234`

**مثال رقم الحساب:**
- فرع 12، اشتراك 45678 → `120045678`
- فرع 05، اشتراك 500 → `050000500`

```javascript
function generateAccountNumber(branchCode, subscriptionNumber) {
  const branchStr = branchCode.toString().padStart(2, '0');
  const subStr = subscriptionNumber.toString();
  const zerosNeeded = 9 - 2 - subStr.length;
  if (zerosNeeded < 0) throw new Error('رقم الاشتراك طويل جداً');
  return branchStr + '0'.repeat(zerosNeeded) + subStr;
}
```

## 📅 السنة المالية

- البداية: 1 يوليو
- النهاية: 30 يونيو
- الرصيد الافتتاحي يُحدد في 1/7

```javascript
function getCurrentFiscalYear(date = new Date()) {
  const month = date.getMonth() + 1;
  const year = date.getFullYear();
  if (month >= 7) return { start: `${year}-07-01`, end: `${year+1}-06-30`, label: `${year}/${year+1}` };
  return { start: `${year-1}-07-01`, end: `${year}-06-30`, label: `${year-1}/${year}` };
}
```

## 💰 معادلة الرصيد

```
الرصيد الحالي = الرصيد الافتتاحي (1/7) + مجموع الإيصالات - مجموع الخصومات
```

**Cascade Effect:** تعديل/حذف إيصال أو خصم → إعادة حساب الرصيد تلقائياً
