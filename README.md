# نظام الإدارة العامة لحسابات المشتركين - إدارة الإيصالات والخصومات
**(Subscriber Accounts Management System)**

نظام ويب متكامل لإدارة حسابات المشتركين، الإيصالات، والخصومات، مبني بتقنيات حديثة ويعمل بالكامل على المتصفح (Client-Side) باستخدام قاعدة بيانات محلية، مع جاهزية تامة للانتقال إلى بيئة سيرفر في الإصدارات القادمة.

## 🌟 المميزات الرئيسية
- **الهيكلية الرباعية**: إدارة دقيقة للقطاعات، الفروع (كود رقمين)، المجموعات (1-8)، والمناطق (7 أرقام).
- **ترقيم ذكي**: توليد تلقائي لرقم الحساب (9 أرقام) بناءً على معادلة: `[كود الفرع] + [أصفار] + [رقم الاشتراك]`.
- **السنة المالية**: دعم كامل للسنة المالية من 1 يوليو إلى 30 يونيو مع حساب الأرصدة الافتتاحية.
- **إدخال ديناميكي**: واجهة ذكية تتحول من إدخال إيصال فردي إلى جدول مجمع لنفس المشترك بضغطة زر.
- **استيراد ذكي للخصومات**: دعم رفع ملفات Excel مع ميزة تعيين الحقول (Field Mapping) والتحقق من صحة البيانات.
- **حساب الأرصدة التلقائي**: تحديث فوري للأرصدة عند أي إضافة، تعديل، أو حذف (Cascade Effect).
- **لوحة تحكم وتنبيهات**: إحصائيات فورية وتنبيهات ذكية (مثل المشتركين بدون إيصالات).
- **تقارير احترافية**: تصدير PDF و Excel، مع دعم كامل للطباعة بتنسيق RTL.

## 🛠️ التقنيات المستخدمة
- **Frontend**: Vue.js 3 (Composition API) + Vite
- **State Management**: Pinia
- **Database**: IndexedDB (via Dexie.js) - يعمل Offline
- **Styling**: Tailwind CSS 3 (مع دعم كامل لـ RTL وخط Cairo)
- **Charts**: Chart.js
- **Utilities**: SheetJS (Excel), jsPDF + html2canvas (PDF), Vue Toastification
