# نظام الإدارة العامة لحسابات المشتركين

نظام ويب احترافي لإدارة حسابات المشتركين والفواتير والمدفوعات - يعمل بالكامل بدون Backend باستخدام IndexedDB.

## 🚀 المميزات (V1)

### 📊 لوحة التحكم
- إحصائيات شاملة (المشتركين، الفواتير، الإيرادات)
- رسوم بيانية تفاعلية (Chart.js)
- تنبيهات الفواتير المتأخرة
- النشاط الأخير

### 👥 إدارة المشتركين
- إضافة/تعديل/حذف المشتركين
- بحث وفلترة متقدمة (الحالة، النوع، المنطقة)
- استيراد/تصدير Excel (SheetJS)
- عرض تفاصيل المشترك مع سجل الفواتير والمدفوعات

### 🧾 إدارة الفواتير
- إنشاء فواتير احترافية
- حساب تلقائي للخصم والضريبة والإجمالي
- حالات متعددة (مدفوعة، غير مدفوعة، جزئية، متأخرة)
- طباعة وتصدير PDF (jsPDF + html2canvas)
- كشف تلقائي للفواتير المتأخرة

### 💳 إدارة المدفوعات
- تسجيل المدفوعات مع طرق دفع متعددة
- تحديث تلقائي لحالة الفاتورة
- سجل كامل للتحصيلات

### 📈 التقارير
- تحليل الإيرادات الشهرية
- توزيع الحالات والأنواع والمناطق
- أكثر المشتركين إنفاقاً
- تقرير شهري تفصيلي مع معدل التحصيل

### ⚙️ الإعدادات
- معلومات الشركة (تظهر في الفواتير)
- إعدادات العملة والضريبة
- نسخ احتياطي واستعادة (JSON)
- تصدير Excel شامل
- إضافة بيانات تجريبية
- مسح البيانات

## 🛠️ التقنيات المستخدمة

- **Vue.js 3** - Composition API
- **Vite** - Build Tool
- **Vue Router 4** - التوجيه
- **Pinia** - إدارة الحالة
- **Dexie.js** - IndexedDB Wrapper
- **Tailwind CSS 3** - التصميم
- **Chart.js + vue-chartjs** - الرسوم البيانية
- **jsPDF + html2canvas** - تصدير PDF
- **SheetJS/xlsx** - Excel
- **Vue Toastification** - الإشعارات

## 📦 التثبيت والتشغيل

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء للإنتاج
npm run build

# معاينة البناء
npm run preview
```

## 🌐 النشر على GitHub Pages

1. تأكد من أن `base` في `vite.config.js` هو `/PillingSystem/`
2. ابنِ المشروع: `npm run build`
3. انشر مجلد `dist` على فرع `gh-pages` أو استخدم GitHub Actions

المشروع مُجهز بملف `public/404.html` لدعم SPA على GitHub Pages.

## 💾 قاعدة البيانات

جميع البيانات محفوظة محلياً في المتصفح باستخدام IndexedDB:
- `subscribers` - المشتركين
- `bills` - الفواتير
- `payments` - المدفوعات
- `settings` - الإعدادات
- `activities` - سجل النشاطات

لا يوجد Backend - يعمل بدون إنترنت بعد التحميل الأول.

## 🎨 التصميم

- **اللغة**: العربية بالكامل مع دعم RTL
- **الخط**: Cairo + Tajawal من Google Fonts
- **الألوان**: لوحة احترافية (Primary: Blue, Secondary: Teal)
